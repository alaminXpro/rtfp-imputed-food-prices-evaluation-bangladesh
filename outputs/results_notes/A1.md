# A1 — Are RTFP's plain item columns the WFP survey values? (Task 1.2, stop-gate)

**Claim.** In the latest RTFP Bangladesh release (2026-10-05), the plain item columns (`rice`, `wheat_flour`, `oil`, `lentils`) are exactly the WFP/HDX retail prices for the same market, month and item, one-to-one.

**Key numbers** (RTFP 2026-10-05 vs HDX file dated 2026-10-04):
- Markets matched by exact name: 110 of 110.
- RTFP observed cells: 17,304 (rice 3,666; wheat flour 4,777; palm oil 4,717; lentils 4,144).
- Matched to an HDX retail value: 17,304 (100%); values identical in 100% of cells (max |ratio − 1| = 0).
- HDX retail cells for these items within RTFP's window (2007-01 to 2026-10): 17,304; none missing from RTFP. The other 200 HDX rows are from 2004–2006, before RTFP starts.
- Gate (≥ 90% matched): **PASS**.

**Related facts.**
- About half of these survey values carry the WFP flag `priceflag = aggregate` (rice 52%, wheat flour 54%, palm oil 56%, lentils 50%), as opposed to `actual`. This matters for measurement-noise estimation (Task 2.1).
- The published estimate `c_` differs from the survey value by more than 1% in 7–9% of observed cells (n = 307–380 cells per item; median absolute difference 5.3–6.3 log points; direction mixed: `c_` above `y` in 39–60% of those cells, by item). The RTFP metadata describes outlier adjustment of survey values; we have not verified that this is the cause. Table A1b.

**Method.** Market names matched exactly (coordinate fallback within 5 km never needed). HDX dates (15th of each month) mapped to the month; retail rows only; HDX units are KG for rice, wheat flour and lentils and L for palm oil, single row per market-month-item. Code: `src/rtfp/audit.py`, `analysis/a1_observed_flag_audit.py`; test `tests/test_audit_data.py` re-checks the gate on every new release.

**Caveats.**
- Verified for the latest release only. Earlier releases are checked indirectly through the vintage stack (Task 1.3); earlier releases may hold fewer survey values than HDX (pipeline toggling reported in review; measured in Task 1.3).
- This shows the plain column equals WFP's published value. It does not show that WFP's value is a single field observation: about half are WFP aggregates, and WFP lists DAM, FAO GIEWS and its own collection among its sources.
- The HDX file and the RTFP release are one day apart; a later HDX revision could differ.
